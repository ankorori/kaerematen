# 一致するまで終われまテン

お題(ITエンジニア向け)に対して参加者全員がテキストで回答し、全員の回答が一致すれば1問クリア。10回連続一致でゲームクリアになるパーティーゲームです。詳しい仕様は [DESIGN.md](DESIGN.md)、お題一覧は [QUESTIONS.md](QUESTIONS.md) を参照してください。

## 開発サーバーの起動

Socket.io をNext.jsに組み込むため、`next dev` ではなく custom server(`server.ts`)経由で起動します。

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開くとホーム画面が表示されます。

## 遊び方

1. ホーム画面で「ルームを作る」を押すと、3つのURLが表示されます。
   - **表示用URL**: 画面共有するPCで開く(操作ボタンは表示されません)
   - **参加者に共有するURL**: 参加者全員に送る
   - **ホスト用の参加URL**: ホスト自身が使う(強制一致ボタンなどの運営操作ができます)
2. 参加者はニックネームを入力してルームに参加します。
3. ロビー画面でホストが「ゲームモード」を選びます。
   - **一致するまで終われまテン**: お題(30秒の回答タイマー付き)が出題され、全員の回答(表記ゆれは正規化して比較)が一致すれば連続記録が+1、不一致なら0にリセットされます。明らかに同じ意味なのに表記違いで不一致になった場合は、ホストが「強制一致にする」で上書きできます。連続10回一致でクリアです。
   - **クイズモード**: 老若男女みんなで楽しめる全100問(5章構成、章ごとに出題ON/OFF可)のクイズに挑戦します。各問題ごとに正誤が自動判定されスコアが加算され、採点がおかしい場合はホストが「正解にする/不正解にする」で個別に修正できます。全問終了するとスコアのランキングが表示されます。
4. ホストが「ゲーム開始」を押すと出題が始まります。

## テスト

```bash
npm test
```

Vitestでお題データの整合性やルーム進行ロジック(一致モード/クイズモード)を検証しています。GitHub Actions(`.github/workflows/ci.yml`)で `push`/`pull_request` の度に lint・test・build を自動実行します。

## 本番ビルド

```bash
npm run build
npm start
```

WebSocketの永続接続が必要なため、Vercelのようなサーバーレス環境ではなく、Railway / Fly.io / Render など常駐プロセスを実行できるホスティングへのデプロイを想定しています。
