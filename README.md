# 一致するまで終われまテン

お題(ITエンジニア向け)に対して参加者全員がテキストで回答し、全員の回答が一致すれば1問クリア。10回連続一致でゲームクリアになるパーティーゲームです。詳しい仕様は [DESIGN.md](DESIGN.md)、お題一覧は [QUESTIONS.md](QUESTIONS.md) を参照してください。

## 開発サーバーの起動

Socket.io をNext.jsに組み込むため、`next dev` ではなく custom server(`server.ts`)経由で起動します。

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開くとホーム画面が表示されます。

## 遊び方

1. ホーム画面で「ルームを作る」を押すと、3つのURLが表示されます。
   - **表示用URL**: 画面共有するPCで開く(操作ボタンは表示されません)
   - **参加者に共有するURL**: 参加者全員に送る
   - **ホスト用の参加URL**: ホスト自身が使う(強制一致ボタンなどの運営操作ができます)
2. 参加者はニックネームを入力してルームに参加します。
3. ホストが「ゲーム開始」を押すとお題(30秒の回答タイマー付き)が出題されます。
4. 全員の回答(表記ゆれは正規化して比較)が一致すれば連続記録が+1、不一致なら0にリセットされます。
   - 明らかに同じ意味なのに表記違いで不一致になった場合は、ホストが「強制一致にする」で上書きできます。
5. 連続10回一致でクリアです。

## 本番ビルド

```bash
npm run build
npm start
```

WebSocketの永続接続が必要なため、Vercelのようなサーバーレス環境ではなく、Railway / Fly.io / Render など常駐プロセスを実行できるホスティングへのデプロイを想定しています。
